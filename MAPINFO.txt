// ---------------------------------------------------------------------
// Skills -- rebuilt from scratch, not ported. The source rotation this
// was pulled from carried 15 skills, most of them near-duplicates of
// each other (three pairs differing only by a flat -33% monster damage,
// six "Realism" tiers differing only by RespawnTime/FastMonsters), and
// the hard tiers leaned on ReplaceActor swaps into Brutal-Doom-only
// classes (Tank/ArtilleryTank/AttackHelicopter/Mech, the Kickattack/
// MeleeStrike family) that do not exist here. None of that is present
// below -- one clean ladder, nothing that references an actor this mod
// does not define.
//
// ACSReturn on Black Metal is not for ACS -- nothing in this mod runs
// ACS. It is read from ZScript (G_SkillPropertyInt(SKILLP_ACSRETURN))
// purely as a stable small integer ID for "which skill effects profile
// is active," resolved by RS_SkillFXHandler (zscript/systems/player/
// RS_SkillFX.zs) against its own effects table. Skills with nothing
// extra to apply just omit the property (reads back 0, "no profile").
// ---------------------------------------------------------------------
clearskills
