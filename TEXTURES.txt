// =====================================================================
// TEXTURES -- monster health bar sprites (zscript/systems/RS_HealthBars.zs)
// ---------------------------------------------------------------------
// Ported from coldcite's "Top HP Bars" 1.04. Two styles, 22 frames each:
// XX = invulnerable, 99 = full, then 95..00 in 5% steps. The art is
// unchanged from upstream -- 112x11, origin bottom-centre (56,11).
//
// The FILLED region of each frame is fully opaque; the EMPTY region is
// hollow (alpha 0 through the interior, only the 1px top/bottom frame
// rows are solid). That is load-bearing: it means a second bar actor
// rendered behind shows through the empty part, which is how a chip-
// damage layer can be built without any new art. Do not fill the empty
// region in when editing these.
//
// Sprite names are HA__/HB__ -- nothing else in this project uses those
// two prefixes.
// =====================================================================
