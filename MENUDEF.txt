// =====================================================================
// Monster Variants & Drops -- the spawn-table, boss and drop gates that
// the seventeen imported creature families read at runtime.
//
// EVERY row below maps 1:1 onto an rs_ch_* cvar declared in
// CVARINFO.txt, and every value offered is a value the monsters
// actually test for. The semantics were read out of our own gates
// (RS_Zom.CV(...) in zscript/monsters/*/) and cross-checked against the
// settings source at CH\source\CHSett.acs and the table in
// docs/rs_28_ch_acs_breakdown.txt section 6. Nothing here is inferred
// from a cvar's name.
//
// Split into four sub-pages plus a legend, same principle as the Arcade
// Score branch: the front page carries the readability switch and the
// doors, and each sub-page owns exactly one concern.
//
// PLAYER-FACING NAMING: rows identify a variant by its NUMERIC TIER and
// its own colour name, which is also what the floating tier icon shows.
// Tiers are the monster vocabulary in this project -- weapon rarity and
// surface glow are different ladders and their words are not used here.
// Internal menu ids and the rs_ch_ cvar prefix are maintenance
// vocabulary and stay as they are.
//
// TIER LADDER (RS_Zom.SetTier; see RS_ZombiemanFX.zs:17-19):

// ---------------------------------------------------------------------
// Combat Behaviour. Four gates that change how a monster fights rather
// than whether it spawns, so all four apply immediately -- the state
// reads the cvar at the moment it runs.
//
//   rs_ch_intercept   0 = lead the shot, 1 = fire straight at you.
//                     Read by exactly three families, all of them heavy
//                     projectile users: RS_HellKnight.zs:1042,
//                     RS_Baron.zs:1143, RS_Cyberdemon.zs:1147. On == 1
//                     each jumps to its "Miss2" state, which is the
//                     plain unpredicted attack.
//                     NOTE the polarity: the DEFAULT (0) is the smarter
//                     behaviour. This is the source's own arrangement,
//                     kept so the two trees stay comparable.
//   rs_ch_cyanbounce  1 skips the vertical hop in the tier 12 dodge and
//                     leaves the side-step. 8 families, 10 sites, e.g.
//                     RS_Baron.zs:569, RS_Chaingunner.zs:396 and :404.
//   rs_ch_rawket      1 forces the Cyberdemon rocket to damage type
//                     Normal (RS_CyberdemonFX.zs:1347). Anything else
//                     leaves the projectile's own type in place, which
//                     only matters to weapon or armour sets that read
//                     damage types.
//   rs_ch_abyssmark   1 shows the marker sprite on tier 9 projectiles
//                     (RS_ZombiemanFX.zs:769).
// ---------------------------------------------------------------------
