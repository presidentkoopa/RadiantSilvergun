// =====================================================================
// VOXELDEF -- 3D voxel world-pickups for the Vanilla+ (GNRCWPN) set.
// ---------------------------------------------------------------------
// VOXELDEF binds to a SPRITE name + frame letter, not to an actor class.
// Every entry below is matched against the actual sprite each RS_VP_*
// weapon plays in its own Spawn: state, verified one by one -- not
// copied from the source's list, which contains entries for sprites this
// project never uses.
//
// Source precedence, where the same voxel existed in two packs: the
// Environmental_Voxels_PickupAndDecoration pack wins (it's the larger,
// already-curated set and is intended to be baked in project-wide
// later). GNRCWPN's own copy is used only where it's the sole source.
//
// One weapon deliberately has NO entry and falls back to its flat
// sprite: the Brass Knuckle (no voxel exists for PUNP anywhere).
// Not guessed at, not substituted.
//
// The Minigun is a special case: GNRCWPN's own pack only ships MNIGA.dat,
// which is not a valid voxel format. Its actual pickup sprite is MNIG
// (see RS_VP_Chaingun.zs Spawn:), which has no voxel under that name in
// either pack -- but the Environmental_Voxels pack's own MGUNA.kvx (the
// vanilla chaingun's real world-pickup voxel) is functionally the same
// model, so it's copied in and renamed to MNIGA.kvx to bind correctly.
// =====================================================================
