// =====================================================================
// VOXELDEF -- 3D voxel world-pickups.
// ---------------------------------------------------------------------
// VOXELDEF binds to a SPRITE name + frame letter, not to an actor class.
//
// SINGLE SOURCE OF VOXELS -- every .kvx under voxels/ comes from
// Environmental_Voxels_PickupAndDecoration, and nothing else. A second pack
// (li-gnrcwpn-vox) was once merged in on top of it; that left 22 foreign
// lumps plus 26 files that shared an ENV name while holding a different
// model, so half the pickup set was silently the wrong pack. All of it has
// been reverted to the ENV pack. Do not merge a second voxel pack in here --
// if a lump isn't in that folder, it doesn't belong in voxels/.
// =====================================================================

// project-wide regardless of weapon set: any map's health, armor, ammo,
// powerups and keys render as voxels instead of flat sprites.

// Spin settings follow the existing convention above: weapons spin,
// pickups don't (vanilla Doom items don't rotate, and spinning every
// bonus on a busy map reads as noise in a headset). This is a deliberate
// departure from the ENV pack's own VOXELDEF, which spins keys and
// bonuses at 92 and offsets the rest by AngleOffset = 270.
//
// Deliberately NOT registered, though the file is present:
//   BROKA -- the pack's broken-launcher prop, part of its ditched-weapon
//            system, which this project doesn't port.
// =====================================================================
