HEADLINE FINDS
  * SFX is the single best folder in this whole assignment. It contains
    COLOR-MATCHED FAMILIES -- the same effect authored in 4-6 colors. That is
    exactly what a procedural generator wants: pick effect, then pick element.
  * DECORATION is 75% furniture and hanging corpses, as expected. 17 exceptions.
  * mg is a monster-gib pack; ~half is corpse art, but the generic half includes
    the best blood-burst and spark-ring sprites found anywhere in this set.
  * CASINGS is 100% already in RS_Main -- but RS_Main imported only 5 of 14
    tumble frames per casing. The extra frames are sitting unused.

NOTE ON FILE FORMATS (why nothing is marked unviewable)
  Many files here are PNGs written by a Doom editor with a bad-CRC 'grAb' offset
  chunk; standard decoders reject them. Others are raw Doom picture lumps with no
  extension. I wrote a repair/decode pass (scratchpad\loader.py) that rebuilds
  chunk CRCs and decodes Doom patch format against the PLAYPAL, so 100% of
  sequences were actually seen. Sizes marked with * below are raw Doom lumps.
  ANY future importer will hit the same wall -- worth knowing.
