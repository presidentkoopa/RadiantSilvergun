CONFIRMED / LIKELY DUPLICATES:

  1. BEXP  ==  RSE0    (HIGH CONFIDENCE -- same effect)
     Identical canvas size (80x96) and visually the same rising fireball
     column: pale-yellow incandescent base, churning orange body, bulbous
     red-brown smoke cap climbing off the top. BEXP is a 12-frame cut
     (frames F-Q); RSE0 is the full 26-frame version (A-Z). Bytes differ at
     every frame I checked (F, J, M, Q) and BEXP's frames are consistently
     LARGER on disk (2.4-3.5KB vs RSE0's 1.2-2.9KB), so BEXP is a
     higher-fidelity or differently-compressed encode of the same animation
     rather than a byte copy.
     RECOMMENDATION: Do not import BEXP as a new effect. If anything, compare
     BEXP's larger frames against RSE0 as a possible quality UPGRADE for the
     existing RSE0 -- but note BEXP only covers 12 of the 26 frames.

  2. PLAF  ~~  RSI5    (MODERATE -- same read, different colour)
     RSI5 (37x38, 26 frames) is a pale cream/near-white soft diffuse puff.
     PLAF (56x56, 17 frames) is the same kind of low-contrast cotton-wool
     puff but tinted pale blue and larger. Functionally overlapping. PLAF is
     still worth having as the cool-tinted / larger variant, but do not treat
     it as a new class of effect.

  3. FRFX  ~~  RSI5    (MODERATE -- same read at smaller scale)
     FRFX (12x14) is a tiny pale-peach soft puff -- essentially a miniature
     RSI5. If a small pale puff is needed, RSI5 can likely be scaled instead.

  4. TRKR/TRKB/TRKG  ==  SRKR/SRKB/SRKG   (INTERNAL duplicate, within FLAMES)
     Not an RS_Main duplicate, but flagging it so the generator does not
     treat these as six distinct plumes. Same dimensions, same frame count,
     same palette, visually indistinguishable at native resolution. Import
     ONE of the two sets (three colours), not both.

  5. X004  ~~  X003    (INTERNAL near-duplicate, within FLAMES)
     Same 128x128 canvas and 26-frame arc; X004 is a browner/smokier and
     paletted rendering. Keep both only if you want a "fire" vs "dirt" pair;
     otherwise X003 is the better-quality (RGBA) one.

  * I did NOT byte-compare every ART SOURCE frame against every RS_Main frame.
    The duplicate findings above come from matching canvas dimensions, frame
    counts, and side-by-side visual comparison of representative frames.
  * SRKR vs TRKR (and their colour siblings): I could not find a visual

    resolve across frames D/E/M. The general behaviour (fountain up, drift

    opening frames. Any importer must not assume frame A exists.
  * I did not inventory E:\RS_Main\sprites\combatfx\sparks\ or \puffs\, so

  * READ-ONLY compliance: no file in E:\New folder\ART SOURCE or in E:\RS_Main
