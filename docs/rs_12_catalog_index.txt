#                                         provenance unknown -- see markers)
#   sprites/combatfx/ directory listing  (ground truth for IN-REPO status,
#                                         frame counts, file naming)
#
# LINE FORMAT (one line per sequence, fields separated by " | "):
#   SEQNAME | frames | STATUS | axes | flavor words | one-phrase visual
#
#   SEQNAME  4-char sprite name. Where the same name exists in more than one
#            source folder, the name is prefixed "FOLDER/" to disambiguate
#            (e.g. SMOKE/SMOK-56). IN-REPO names (RS??/ICEY) are unprefixed.
#   frames   frame count from the source that actually counted files.
#            "(8-way rot)" = rotation set, not an animation.
#            "(colour set)" = each frame is a different tint, not a timeline.
#   STATUS   IN-REPO      = in sprites/combatfx/ right now
#            AVAILABLE    = in ART SOURCE only, not yet imported
#            AVAILABLE-DUP(x) = in ART SOURCE but duplicates in-repo sequence x
#                           (exact or visually-indistinguishable; do not import)
#   axes     PACK ingredient axes this sequence can fill, comma list from:
#              Projectile   (Bullet in-flight visual / ProjectileClass)
#              Casing       (CasingClass; also covers ejected debris)
#              Muzzleflash  (BigMuzzle)
#              BarrelSmoke  (MuzzleSmoke)
#              Puff         (ImpactPuff)
#              ImpactFX     (ImpactSparks)
#              Trail        (FancyVisual / in-flight trail)
#              ExplosionVisual (Heavy-mode slot, per rs_05 "other modes")
#            "-" = fills no PACK axis (gore-only, scenery, UI, unknown).
#            (Report "ambient"/"gore"/"debris" tags: ambient dropped, gore
#             dropped unless the report also tagged impact-fx, debris->Casing.)
#   visual   One-phrase compression of the report's VISUAL line. Markers:
#              (no marker)  = written from an actually-viewed frame
#              EC:          = only source is EFFECT_CATALOG.md (project doc;
#                             whether it was written from viewed frames is not
#                             recorded -- treat as probably-right, not proven)
#              PIXEL-DATA:  = gore report measured pixels but never saw it;
#                             geometry/palette asserted, subject matter NOT
#              UNVERIFIED   = no viewed description exists anywhere; content
#                             unknown; do NOT categorize from the name
#              NOT-FX       = catalogued but rejected (weapon art, scenery, UI)
#
# GROUP LINES: bulk-rejected sets (fatality anims, scenery, placeholders,
#   weapon pickups, monster-specific gore) are indexed as one line per group
#   with every member name enumerated in the visual field, so a grep for any
#   4-char name still hits. Format: GROUP(label) in the SEQNAME field.
#
# Sounds are out of scope (see docs/EFFECT_CATALOG.md "Sounds" for those).
