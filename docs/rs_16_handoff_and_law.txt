HARD RULES (each one has cost real time)
  * `static const T name[]` / fixed arrays in class bodies DON'T
    RESOLVE. Use switch or a comparison chain. (4 real bugs.)
  * A file not in zscript.txt, or a handler not in MAPINFO's
    AddEventHandlers, SILENTLY does not exist.
  * Array<T> can't be a return type -- out-params. switch can't take a
    string. No static non-const fields. GetClassName() returns Name --
    concat `.. ""`.
  * GetMissileDamage is native non-virtual, CANNOT be overridden.
    Exact damage rides DoSpecialDamage (one merged override -- don't
    split it).
  * VR: 3D models, NO weapon sprites. Nothing drawn on weapon/screen.
    Audio and world-space actors only.
  * HOOKS (rs_14): resolver / OnKill / OnDamageDealt are hand-correct.
    ModifyDamageDealt and Tick reach the MAINHAND bag ONLY -- a card
    built on them silently does nothing in the off hand.
  * A new card needs FOUR things: the class, BONSAIRC, LANGUAGE.rs_ui,
    and (new files) an include.
  * Filenames lie -- look at the sprite. CH-external assets are
    INVISIBLE without the Colourful Hell pack; rs_13 flags which are
    safe.

TIER -> OFFER LAW (settled)
  Cursed/Trash/Basic: 2 cards, STAT ONLY (0 sockets).
  Common+: full pool. Offers 4 / 5 / 6 by tier band.
  SOCKETS = BREADTH CAP: distinct affixes <= sockets (1..5). Re-picking
  to LEVEL a held affix never costs a socket.
  PROMOTED PICKS LAND +1 (new affixes enter at L2), capped at L5 --
  Mastery is always a deliberate 6th pick.
  Levels 1-5 + Mastery. Mastery = a RULE CHANGE, never bigger numbers.
  Gold at the picker: reroll 5<<n, buy a card 12<<n.
