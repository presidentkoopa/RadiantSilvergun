DESIGN DECIDED THIS SESSION -- DO NOT RE-LITIGATE
---------------------------------------------------------------------

ELITE DROP TIERS. rs_00's rule was a CLIFF: only Cursed/Trash/Basic
until all six class weapons are found, then the whole ladder at once.
Replaced with a RISING CEILING, owner-approved:

    2 owned -> Basic     3 -> Common      4 -> Uncommon
    5 -> Advanced        6 -> Prototype

THE POOL WIDENS, IT DOES NOT SLIDE. Cursed stays the floor forever --
per rs_00 those tiers are not merely bad (Cursed is powerful with stats
locked behind individual curses; Trash carries the Trash-to-Treasure
chance). Bias is two rolls, lower kept.

Rejected and why: a hard gate is a cliff nobody can influence; pure
odds-shifting is INVISIBLE (30% -> 35% is not perceptible over the
drops anyone actually sees). A ceiling is something the player can
WATCH unlock.

Falls out free: rs_00 gives Cursed/Trash/Basic no GunBonsai sockets, so
under a rising ceiling the bottom three tiers are stat-only, PERMANENTLY,
rather than that being an early-game phase.

STILL OPEN, the owner's own reframing and the more interesting idea:
an elite drop is a DATA PACKAGE that reshapes a class weapon you hold,
not a gun. But you start with two of six, so a package can only ever
land on two things. Proposal on the table, not built: ONE drop type
that behaves by ownership -- don't own that weapon, the package ARRIVES
as it; do own it, it APPLIES to it. Acquisition and modification stop
being two systems and the ramp becomes emergent.
