RS MONSTER TIER NOTES
=====================================================================
What each tier IS, in a line. Kept short on purpose -- this is the
quick-reference for "what am I looking at", not a design doc.

THE LADDER
  T00  Common      vanilla Doom, the baseline
  T01  Green       CHP green set
  T02  Blue        CHP blue set
  T03  Cyan        CHP cyan set -- ice/frost across the roster
  T04  Purple      CHP purple set
  T05  Yellow      CHP yellow set
  T06  Abyss       CHP abyss set -- the "drowned/void" line
  T07  FireBlu     CHP fireblu set
  T08  Brown       CHP brown set
  T09  Gray        CHP gray set
  T10  Red         CHP red set
  T11  Black       CHP black set -- named apex creatures
  T12  White       CHP white set -- the rarest of the base ladder
  TEX  EX          CHP's EX variant (its KX/WX file). Tier 13.
  T14+ extras      further EX variants, and whatever packs come later

The ladder is OPEN-ENDED. A higher tier is just another kind of
monster. Adding one is: author the state cluster, add the TierData
row, extend BodyTable/TintTable, raise that family's MaxTier().
Nothing in the base class caps it -- TierLabel() GENERATES labels
(T14, T15, ... ) rather than enumerating them.

Main game mode runs T00 -> TEX. Everything above that is headroom.

STATS ARE HAND-ASSIGNED, NOT A CURVE
CH and CHP tuned every colour's health and speed individually, and
so do we. RS_MonsterTierRow carries absolute `hp` and `speed`; set
them and they are used verbatim. The hpMul/spdMul multipliers are a
fallback for the generic base ladder only. A tier having less HP than
the one below it is not a bug -- T03 is faster and frailer than T02
in CH's own numbers, and that irregularity is the ladder's character.

SOURCE OF TRUTH
  E:\New folder\ART SOURCE\CHP\DECORATE\NN\NN_<code>.txt
CHP always wins. CH fills only what CHP leaves undefined (CHP is a
patch on top of CH, so a CHP actor that doesn't redefine a state
inherits it). Colour code -> tier:
  C=T00 G=T01 B=T02 CY=T03 P=T04 Y=T05 A=T06 F=T07
  BR=T08 GY=T09 R=T10 K=T11 W=T12  KX/WX=TEX and up

CHP family numbers:

=====================================================================
ARCHITECTURE, IN FOUR LINES
=====================================================================
* Every tier is a REAL state cluster: Spawn.T03, Missile.T03, ...
  with literal sprite tokens. The sprite field is NEVER assigned at
  runtime -- that was the old skin system and it caused the freeze.
* TierState(prefix) resolves "prefix.<TierLabel(Tier)>" at runtime,
  falling back to the T00 cluster.
* SetTier(t) works on a live monster, mid-fight, idempotently.
* The transform tell: old body -> gold -> new body -> gold -> ...
  accelerating, random length, never longer than 3 seconds.
