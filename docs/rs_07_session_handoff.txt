RULES NOW IN MEMORY BECAUSE OF THIS
================================================================================
Both saved to this project's memory store (not just this doc) -- they apply
regardless of which thread gets picked up next:
  - Never run an unbounded recursive search over a whole drive to find a
    file or executable. Ask the owner for the path directly. If a search is
    truly needed, scope it tightly (a known directory, a shallow depth
    limit) -- never a bare drive root.
  - When a typed answer to a clarifying question doesn't cleanly match one
    of the offered options, it is not a selection -- read it as what it
    actually says (new information / a different request), and if genuinely
    unsure, ask a short plain-text follow-up before taking any action that
    has real side effects.
