## The mission, in one paragraph

A VR dual-wield Doom roguelite. Two guns, one per hand, tracked
independently. Weapons are rolled objects with their own stats, wear and
upgrades — not fixed pickups. You collect six of your class's weapon,
then Promotion turns collection into growth. Monsters are 17 families
with per-variant tier ladders and an elite layer on top. **Every screen
is an object in the world you walk up to and touch, not a menu that
pauses the game.**

## THE BIG IN-FLIGHT PIECE: the offer panel

Agreed with the owner today, **designed but NOT built**. This replaces
~20 entry points across 9 UI files with one thing.

**One panel. Shape says what kind, colour says how good.**

- **square** = a class weapon being offered
- **round** = an imprint (a stat package for a gun you already own)
- colour = tier, driving the frame, header, floor glow, meters and
  buttons — not a word in a corner

**Five regions:**

| region | holds |
| --- | --- |
| identity | which of the six + rolled tier. On an imprint the tier *is* the name. |
| sprite | the pickup image — tells a shotgun from a rifle across a room |
| stats | up to 12, shown `old → new` against the hand being pointed at, coloured by direction. Cursed stats read `???`. |
| marks | what will not fit a number: sockets, affixes, curses |
| actions | touchable: Apply→Mainhand, Apply→Offhand, Recycle for gold, Deny |

**Six row types, nothing else:** HEADING, VALUE, BAR, DELTA, BUTTON,
SPRITE. Every screen in the mod — weapon status, level-up, promotion,
curses, repair, map stats, the offer — is a list of those six.

**Three-range presence (owner's design):**

1. **far** — every drop casts a tapering light pillar in its tier colour,
   with a marker on top: **◆ diamond = class weapon, ● circle = imprint**.
   You read count, quality and kind across a level with no text.
2. **mid** — the card replaces the marker and begins growing.
3. **near** — full size, readable, buttons live.

Currently it is a hard radius switch with a fixed-size card. Distance
should drive scale continuously.

**Interaction: touch is primary, keys are the fallback.** The engine's
`TouchBillboard` already returns which panel and which hand. Reach out
and touch the action you want; the hand you use *is* the answer.
Keyboard USE exists for desktop only. The current build has that
backwards.

## Rules settled today

**Only two things drop.** Kill rewards (bits) from everything; class
weapons from elites. Nothing else, ever.

**Class weapon tier comes from the map weapon it replaced:**

```
pistol, shotgun    -> Common
SSG, chaingun      -> Uncommon
rocket launcher    -> Advanced
plasma rifle       -> Designer
BFG                -> Prototype
```

The map's own weapon escalation is a hand-authored difficulty curve
present in every wad; this inherits it for free. Built today in
`RS_ClassGating.TierForMapWeapon`. Previously every map fill was Basic.

**`AllowBigGuns` is removed.** Rocket/plasma/BFG are no longer free
universal grants — they go through the fill, because they are the top
three rungs of that ladder.

**The six identities are NOT a ladder.** `VR_Rifle2` differs from
`VR_Rifle` only by name, slot and magazine. Etiquette, Pardon Me,
Manners, Decorum, Propriety, Civility. Fill order is 2, 3, 5, 6. All
power is in the tier.

**Cursed is no longer a tier.** It is an effect with two forms: a roll on
Promotion (weapon stats obscured), and a % on death when a life is spent
(a player curse). The `VRT_Cursed` enum slot is already unreachable —
`TierFloor()` returns `VRT_Trash` — so it is dead, not disabled. May
later be renamed **Vanilla**: no rolls, default everything, 0 sockets,
never drops. Not done; no urgency.

**Sockets per tier** (`RS_Roll.zs:109`) — Trash/Basic 0, Common 1,
Uncommon 2, Advanced 3, Designer 4, **Prototype 5**.

**Stat rolls are per-weapon, per-tier bands**, not a multiplier — each
weapon has hand-written ranges per tier. Note `RollStats` floors at
Basic, so Trash and below produce Basic's dice.

## Built today, NEVER SEEN RUN

Everything below is source-verified only.

- **Curses, both pools** — 5 weapon stat-locks from Promotion; 8 player
  flaws × 2 hands from death. Lift restores the true pre-curse value and
  pays 25/35/50% escalating, raises the damage ceiling, tiers the weapon
  up. Divine at 10 cures, both pools, player-wide.
- **Monster drops fixed** — the `bTossed` guard was read in
  `WorldThingSpawned`, but the engine sets that flag 12 lines *after* the
  spawn that fires the event, so it was always false and every monster
  weapon became a class weapon. Now deferred a tic.
- **`A_SpawnItemEx` drops fixed** — ~130 death-state spawns (56
  HealthBonus, 40 ArmorBonus) bypassed the suppressor entirely because a
  plain spawn sets no loot flag. Now tests "loose, pickable, spawned
  during play" with explicit exemptions for bits, elite drops and
  map-placed items.
- **Elite turreting fixed** — `Reveal()` set both `bMISSILEMORE` and
  `bMISSILEEVENMORE`, which together mean `MissileChanceMult 0.0625` —
  ~16× the normal fire rate. A monster only walks in `A_Chase`, which
  exits to Missile the moment its fire check passes, so elites planted
  and fired forever. Now one cvar, `rs_elite_missilechance`, default 0.5.
- **Grenade fixed** — spawned at the player's feet because it read
  `OffhandPos`, which is only written by real VR controllers; the
  engine's flat fallback is the player's floor position. Now checks
  `OverrideAttackPosDir` like `RS_PanelController` already did.
- **Panel size** — was 40×80 units at 72 away (a panel taller than the
  player, three of them). Now 18×24 at 46.
- **15 hidden cvars** surfaced into menus; 0 live cvars now unreachable.

## Not built

- ~~Imprints~~ **BUILT 2026-08-08**, compiles clean, never run. See
  `zscript/systems/weapon/RS_Imprint.zs`. Full Trash..Prototype ladder,
  seven weight cvars (not eight — Cursed is not a tier any more), +0/1/2
  tier bonus, random donor family. **Applies re-roll-keep-better** —
  `rs_imprint_mode 1` switches to a straight re-roll. Force one without
  collecting six first: `netevent rs-imprint-test 7`.
  Deliberately NOT written by an imprint, each for a stated reason:
  PelletCount/PromotionCount (Promotion owns that axis, and `RollStats`
  assigns `PelletCount = 1` — an in-place re-roll would erase every
  promotion paid for), Condition (repair owns wear), RateOfFire (pinned
  to the fire animation), the `Locked*`/`CurseStack*` pair (`RollStats`
  clears the flags but not the counters — a free curse-wipe *and* a
  desync), GunBonsai level/XP.
  Does NOT route through `ApplyUpgradeCard()`: its
  `Tier == Prototype && newTier == Basic` branch would let a **Basic
  imprint silently PROMOTE a Prototype gun**, cutting all five stats 20%.
  Promotion is a decision, not something a loot drop does to you.
  **Open for the owner:** Trash/Basic imprints are near-worthless under
  keep-better (they can only raise stats already below those bands), so
  the weight curve may want flattening if late elites should always feel
  like something.
- **The offer panel** above.
- **Elite drop floor visuals** — sprite, tier glow, light pillar, soft
  dynamic light. Two agents spawned for this and the interaction work;
  **both died having written nothing.**
- **Elite drop menu page** — glow size, light detail, beam height.
- **Reinforcements** (`RS_ReserveSquads`) — ships off. Owner specced

## Hard rules

- **`zscript/monsters/**` and `zscript/systems/monster/**` are SACRED.**
  Read freely; never write without the owner naming that change in that
  session. `RS_Elite.zs` and `RS_HealthBars.zs` were edited today under
  explicit permission, noted in the files.
- Never `git add -A`. Stage explicit paths.
- Verify engine behaviour against `E:\UZDXREMA` source. Never assert it
  from memory — that produced several wrong calls today.
- ZScript is case-insensitive: a method named `For()` collides with the
  `for` keyword.
- `static const TYPE name[] = {...}` does not resolve on this build.
- `EVR_Tier(x)` is not a cast — assign an int.
- `Screen.Dim` takes no `DTA_` tags.
- An unscoped `Object` subclass is **data** scope and cannot call play
  functions. UI may read play state, never write it.
