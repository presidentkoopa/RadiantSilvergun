// Lead fire. CH's four ProjInt_Brute scripts (BaronMissile, CybMissile,
// ImpMissile, FatMissile) make a monster solve where you WILL be and
// shoot there instead of at where you are. CH gates all of them behind
// its own CH_Intercept cvar with a Miss2 fallback state, so this is a
// real option in the original, not an always-on behaviour.
// The import dropped the gated branch and kept only Miss2, which meant
// this was effectively OFF and unswitchable. On by default now, because
// off is what we have been playing.
//
// POLARITY IS DELIBERATELY NOT CH'S. CH_Intercept defaults to FALSE and
// its DECORATE reads A_JumpIf(CH_Intercept == true, "Miss2") -- Miss2
// being the DUMB shot. So CH's false means "lead", true means "do not",
// while its own menu label reads "Intercepting missiles / Can Cybie &
// Baron Aim where you go?". The cvar is inverted against its own text.
// CH's effective DEFAULT (lead on) is what we match; its spelling is not.
// Here, true means the monster leads. Do not "fix" this to match CH.
server bool rs_monster_intercept = true;

// --- Per-map reward threshold calibration ---------------------------
// The threshold is derived from the map's own monster population, so
// one bar means the same amount of work on MAP01 and on a slaughtermap.
// Monster count is clamped to min/max, multiplied by the scalar, and
// scaled by the average points per monster.
//
// An earlier pass used 30/400/0.30/100, which pays a reward roughly 4.7x
// as often. Rewards are EXTRA LIVES; they are meant to be rare.
//
// Safe to adopt despite our tier-weighted base points: average points per
// monster appears in the numerator AND scales every kill equally, so the
// formula is invariant to how large the point values get. Only the
// monster-count clamp and the scalar actually move the pacing.
server int rs_score_monstermin = 140;
server int rs_score_monstermax = 800;
server float rs_score_monsterscalar = 0.50;
// Threshold is rounded to this, purely so the HUD number stays legible.
server int rs_score_interval = 5000;

// How much a monster's TIER inflates its point value above raw health.
// 0.12 -> a T13 (EX) monster is worth ~2.5x its hit points, a T03 ~1.36x.
// Set to 0 to score purely on health.
server float rs_score_tierweight = 0.12;
